# 🔍 Bhavya's DeepSearch

Autonomous research and multi-source web intelligence engine. Automatically breaks complex queries into targeted sub-searches, crawls content, and compiles verified citations.

---

## 📂 File & Folder Structure — Direct Edit Guide

| File / Folder | What It Does | When to Edit |
| :--- | :--- | :--- |
| `index.html` | Search query interface & citation stream | Customize search bar, source cards, and research notes |
| `app.js` | Search orchestrator & query decomposition | Modify research depth, crawling frequency, and synthesis rules |
| `background-3d.js`| Interactive 3D constellation visualization | Adjust particle count, speed, and connection lines |
| `api/` | Web scraping and synthesis endpoint | Configure search provider APIs and scraper limits |

---

## 🚀 How to Run Locally

Open `index.html` directly in Chrome or Edge.
